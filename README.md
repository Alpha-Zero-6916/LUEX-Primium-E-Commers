## What's Inside

- 🎞 **Hero Slider** — Auto-playing full-screen slider with Ken Burns zoom, dot nav & arrow controls
- 🛍 **Live Shopping Cart** — Add, remove, update quantities with a real-time subtotal in a slide-in drawer
- 🔍 **Search Overlay** — Full-screen search with popular tag shortcuts
- 👤 **Account Modal** — Login & Register with tab switching and form validation
- ❤️ **Wishlist Toggle** — Per-product heart icon that toggles on/off
- 📱 **Mobile Ready** — Dedicated bottom nav bar, side menu drawer, and fluid layouts for all screen sizes
- ✨ **Micro-interactions** — Hover swaps, icon animations, badge pops, and smooth scroll throughout

## Getting Started

```bash
# 1. Clone
git clone https://github.com/your-username/luxe-ecommerce.git

# 2. Open
open index.html
```

Or serve locally:

```bash
npx serve .
# → http://localhost:3000
```

No installs. No build step. Just open and go.
